# Mascot concepts (exploration)

Eight original concepts for **Naqsh** (نقش, imprint/engraving), generated with Muse Image.
Outputs live outside the repo at `L:\naqsh-review\mascot\concepts\`; the manifest is
`docs/mascot-manifest.json`. No design has been chosen.

| Name | Category | Idea |
|---|---|---|
| dot-a | dot/blob | single soft teardrop dot, Arabic nuqta nod |
| dot-b | dot/blob | stacked pebbles, smaller dot resting on larger |
| ink-a | ink drop | glossy indigo ink drop with a soft point |
| ink-b | ink drop | drop peeking out of a shallow inkwell |
| nib | nib/qalam | rounded calligraphy nib standing upright |
| stamp | stamp/seal | chunky seal with a soft handle and dot imprint |
| layers | layered sheets | three offset translucent sheets with a face |
| knot | free choice | ribbon loop folded like a calligraphic knot |

All prompts specify: flat vector, rounded shapes, tiny dot eyes, no arms/legs, no blocky
pixel body, no crab, no orange/coral body, #5B6CFF + cool neutral, plain background, no
text/letters/logo.

Two immediate risks flagged for the owner, not resolved here:

- `dot-b` and `nib` render an extra pale blob above the character.
- `knot` reads as an ampersand-like ribbon; that is close to a letterform and may
  violate the “no letters/logos” rule.

Cost: 8 × \.01 = **\.08**.
