## 2 — How it works (thread starter, no image)

> Most localization tools treat RTL as an afterthought. Naqsh reads the page, segments each
> region, repaints the plate, sets Arabic with HarfBuzz, then gives you the layers back.
> Every runtime model call is a Meta model. Demo mode replays a recorded run; live mode is
> one flag away.
